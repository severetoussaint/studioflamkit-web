# 1B2.5.6 — Auditoría de cierre del motor global de precios

## Objetivo

Este documento registra el estado real después de la auditoría cruzada de Propuesta, motor global de precios, Supabase y lectura del Proyecto.

## Corregido

- La configuración global de precios está separada del flujo de `Preparar propuesta` y accesible desde `Admin → Configuración → Precios`.
- `pricing_services` y `pricing_settings` tienen RLS administrativo y privilegios SQL necesarios para el rol `authenticated` usado por el cliente; RLS continúa restringiendo las filas a Admin mediante `is_admin()`.
- Las migraciones de privilegios y de normalización de los servicios base están versionadas dentro de `supabase/migrations`.
- `PricingModel = included` representa que el servicio no agrega precio incremental cuando se selecciona; no debe interpretarse como “servicio obligatorio”.
- El motor dejó de convertir `included` por sí mismo en selección obligatoria. La inclusión efectiva se basa en la selección o en `included_by_default`.
- Los servicios inicialmente sembrados como “Edición de diálogo estándar” y “Mastering estándar” fueron normalizados para no bloquear el configurador mientras se termina de definir el catálogo comercial definitivo.
- El Dashboard del autor dejó de usar `maxRevisions = 3` fijo: la lectura del Proyecto obtiene `revisions_included` desde la Propuesta vinculada.
- `accept_proposal` continúa siendo la autoridad para crear/vincular el Proyecto y deja el Proyecto en `planning`, no en Producción.

## Fuente de verdad

- Catálogo global: `pricing_settings` + `pricing_services`.
- Propuesta: snapshot congelado en `proposals.services` más columnas propias de la Propuesta (`amount`, `revisions_included`, `deadline`, `expires_at`).
- Proyecto: `projects.proposal_id` enlaza con la Propuesta aceptada; las reglas comerciales no se deben regenerar desde el catálogo actual.

## Pendiente por decisión de negocio, no por fallo técnico

- Definir el catálogo profesional definitivo y sus variantes (por ejemplo, niveles concretos de edición, restauración, Foley, voces, mezcla, música, etc.).
- Definir las tarifas definitivas y unidades de cada servicio.
- Definir formatos y condiciones contractuales finales de la Propuesta.
- Definir posteriormente el sistema operacional de revisiones usadas, producción y entrega de archivos finales.

Estas decisiones se mantienen fuera de Producción/Entregables hasta cerrar la especificación comercial de la Propuesta.
